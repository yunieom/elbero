# T20 → T21 → T22 실제 검증 기록

- 검증일: 2026-10-13
- 순서: T20 실제 데이터·대표 동선 → T21 양 플랫폼 QA → T22 내부 Beta 관찰
- 원칙: API·시뮬레이터 결과를 현장 또는 물리 기기 결과로 기록하지 않는다.

## T20 실제 동선·방향 검증

### 실제 데이터 재조회

서울교통공사 `SeoulMetroFaciInfo`를 2026-10-13 11:13 KST에 다시 조회했다.

- 전체 2,808건, 엘리베이터 865건
- 답십리: 엘리베이터 4대 모두 사용 가능
- 강동: 엘리베이터 3대 모두 사용 가능
- 굽은다리: 엘리베이터 3대 중 2번 출구 지상 엘리베이터 1대 보수 중
- 동대문역사문화공원: 엘리베이터 7대 중 5호선 내부 1호기 1대 보수 중
- 을지로4가: 엘리베이터 4대 모두 사용 가능

### 대표 여정 결과

| 여정 | 실제 상태 반영 결과 | 판정 |
| --- | --- | --- |

동대문역사문화공원의 보수 중 시설은 해당 후보에서 요구하는 내부 2호기가 아니라 내부 1호기다. 앱은 이름이 비슷한 다른 시설의 고장을 잘못 연결하지 않고 동대문역사문화공원 후보를 유지했다.

iOS와 Android에서 답십리 → 굽은다리를 열었을 때 모두 `현재 이용 가능한 안전 경로가 없어요`와 `운행 중지 시설을 제외한 대체 경로를 찾지 못했습니다.`를 표시했다.

### T20 판정

**진행 중 — 종료 불가.** 실제 API 상태, 앱의 시설 연결, 고장 제외 동작은 검증했다. 기존 사용자 현장 확인으로 강동 1번 출구 근거는 있으나, 대표 여정 전체를 직접 이동하며 지상 입구·층·개찰구·차량·문·환승 통로·퇴장 순서를 대조한 기록은 아직 없다.

현장에서는 현재 보수 중인 굽은다리 2번 출구를 안전 경로로 이용하지 않는다. 정상 대표 여정은 답십리 → 강동, 환승 대표 여정은 답십리 → 홍대입구를 대상으로 대조해야 한다.

### 실제 조작에서 발견하고 수정한 결함

결과 화면이 딥링크 또는 복구된 첫 화면으로 열린 경우 상단 뒤로가기가 탐색 이력 없이 `back()`만 호출해 아무 동작도 하지 않았다. 탐색 이력이 있으면 이전 화면으로 돌아가고, 없으면 역 선택 화면 `/`로 교체하도록 수정했다.

- 일반 검색 → 결과 → Android 시스템 뒤로가기: 선택값을 유지한 홈으로 복귀
- 딥링크 결과 → 상단 뒤로가기: 역 선택 홈으로 복귀
- 심각도: 출시 전 수정 필요
- 수정 상태: 해결·재검증 완료

### 물리 기기 상태와 T21 판정

- 연결 기록이 있는 iPhone 15 Pro는 현재 `unavailable` 상태다.
- 연결된 Android 물리 기기는 없다.
- iOS 27 Simulator와 Android 16(API 36) Emulator 검증은 통과했다.

따라서 T21은 **기능 QA 통과, 실기기 조건 미충족으로 종료 불가**다. 기존 접근성 결과는 [T21 큰 글자 접근성 QA](./t21-large-text-accessibility.md), 오프라인 복구 증거는 [T19 통합 회귀](./t19-integrated-regression-g2.md)에 있다.

## T22 Beta 사용성 관찰

### 내부 관찰 결과

프로젝트 소유자의 이전 실제 QA 피드백과 이번 Android 조작을 내부 Beta 관찰로 정리했다. 개인정보와 장애·육아 경험 여부는 수집하거나 추정하지 않았다.

| 과업 | 결과 |
| --- | --- |
| 출발·도착 선택 | QA 예시에서 답십리와 굽은다리가 서로 다른 입력에 정확히 반영됨 |
| 출발·도착 교환 | 한 번의 조작으로 두 역이 서로 교환됨 |
| 안내 시작 | 현재 실시간 보수 상태가 반영된 안내 불가 화면까지 도달 |
| 고장 이유 이해 | 운행 중지 시설을 제외했으나 대체 경로가 없음을 한 카드로 안내 |
| 복구 행동 | 대체 경로 다시 찾기와 역 선택으로 돌아가기를 제공 |

이전 Beta 관찰에서 검색어가 양쪽 입력에 남는 문제, 단일·복수 출구 문구, 기술적 근거 노출, 승강장 간격 배지, 방향과 빠른환승 표현이 수정됐다. 이번 관찰에서는 결과 화면 복귀 결함 1건을 추가로 발견해 수정했다.

### T22 판정

**내부 관찰 완료, 독립 참여자 조건 미충족으로 종료 불가.** 프로젝트 소유자 이외의 대상 사용자 또는 유사 경험자가 도움 없이 검색·고장 이유·단계 안내를 이해하는지는 아직 관찰하지 못했다. T20 현장 대조와 T21 물리 기기 검증이 끝난 뒤 독립 참여자 1명 이상으로 다시 수행해야 한다.

## 종료를 위해 필요한 외부 검증

1. T20: 답십리 → 강동과 답십리 → 홍대입구를 실제 이동하며 앱 단계와 층·개찰구·차량·문·환승·출구를 대조한다.
2. T21: 잠금 해제·Developer Mode가 켜진 iPhone과 USB 디버깅이 허용된 Android를 연결해 Q01~Q10을 반복한다.
3. T22: 유모차·휠체어·보행 보조 경험이 있는 참여자 또는 유사 경험자에게 설명 없이 출발·도착 검색, 고장 이유 설명, 다음 단계 이동을 수행하게 하고 막힌 지점을 기록한다.
