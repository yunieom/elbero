# T18 여정·단계 오류 제보 결과

## 설정

모바일 앱의 `.env`에 수신 주소를 설정한다.

```dotenv
EXPO_PUBLIC_REPORT_EMAIL=report@example.com
```

환경변수를 변경한 뒤 Expo 개발 서버를 다시 시작해야 반영된다.

## 구현 결과

- 모든 여정 단계 카드에서 `이 단계 정보 제보`를 열 수 있다.
- 사용자는 잘못된 동선, 시설 정보, 승강기 상태, 승강장 간격, 기타 유형을 선택하고 설명을 입력한다.
- 메일 작성 전에 포함될 여정, 단계, 시설 정보와 받는 주소를 확인한다.
- 제목과 본문에는 여정 ID, 데이터 버전, 경로 ID, 단계, 역, 기존 안내, 시설 ID가 자동 포함된다.
- 메일 앱을 사용할 수 있으면 작성 화면만 연다. 실제 발송은 사용자가 메일 앱에서 직접 확정한다.
- 메일 앱을 사용할 수 없거나 열기에 실패하면 받는 주소, 제목, 본문을 클립보드에 복사한다.
- 수신 주소가 아직 설정되지 않은 경우에도 제보 내용을 잃지 않도록 제목과 본문을 복사한다.
- 현재 위치, GPS 좌표, 이전 이동 이력은 수집하거나 메일에 추가하지 않는다.

## 검증 증거

- 여정·단계·시설 ID 메일 본문 생성 테스트
- 시설 ID가 없는 단계 처리 테스트
- 수신 주소 미설정 복사 데이터 테스트
- 위치 이력 비수집 테스트
- 메일 앱 사용 가능 시 작성 화면 열기 테스트
- 메일 앱 없음·열기 실패 시 클립보드 복사 테스트
- Android·iOS 번들 생성 및 전체 타입 검사

## 남은 제한과 다음 작업

- 실제 메일 앱 전환과 클립보드 붙여넣기는 연결된 실기기에서 최종 확인해야 한다.
- 현재는 이메일을 제보 접수 채널로 사용한다. 제보량이 늘면 서버 저장, 중복 제보 묶기, 처리 상태 추적을 별도 Task로 검토한다.
