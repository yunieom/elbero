# T16 신뢰 정보·예외 처리·접근성 결과

## 구현 결과

- API 오류 envelope의 코드에 따라 미지원, 데이터 누락·충돌, 조회 실패, 상태 미확인, 안전 경로 없음, 데이터 버전 오류를 서로 다른 사용자 카드로 표시한다.
- 정상 응답의 warning envelope도 안전 상태 카드의 `확인이 필요한 내용`에 합쳐 표시한다.
- 재시도 가능한 오류는 상태 확인 또는 대체 경로 재탐색으로, 수정이 필요한 오류는 역 재선택으로 연결한다.
- 여정 화면에 상태 관측 시각, 최대 지연 시간, 경로 검증일, 사용자용 출처 이름을 표시한다. 원천 API ID와 시설 ID는 노출하지 않는다.
- 운행 상태는 색뿐 아니라 `운행 중`, `운행 중지`, `상태 미확인` 텍스트로 함께 표시한다.
- 핵심 상태 카드와 단계 카드를 VoiceOver·TalkBack이 한 묶음으로 읽도록 라벨과 순서를 적용했다.
- 큰 글자에서 카드와 버튼이 고정 높이에 잘리지 않도록 줄바꿈과 최소 높이를 사용한다.

## 검증 증거

- 오류 표시 단위 테스트: 미지원, 누락, 상태 미확인, 안전 경로 없음, 네트워크 실패
- 전체 테스트: API 92건, 모바일 19건 통과
- 모바일 타입 검사 통과
- Android·iOS 번들 생성 통과
- iOS VoiceOver, Android TalkBack과 큰 글자 실기동 결과: [T21 큰 글자·접근성 QA](./t21-large-text-accessibility.md)

## 남은 제한

- iOS VoiceOver는 iOS 27 Simulator에서 핵심 화면과 오류 제보 입력까지 통과했다. 연결된 iPhone은 Developer Mode가 꺼져 있어 물리 기기 검증은 별도 확인이 필요하다.
- 원천 데이터가 없거나 충돌하는 역은 임의 확정하지 않고 `안전 경로 미확인`으로 유지한다. 대상은 [사용자 검증 대기 목록](../../research/supported-lines-user-verification-pending.md)에서 관리한다.
