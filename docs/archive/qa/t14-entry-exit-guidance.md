## 제품 결정 반영

- 시설 ID와 원천 API 명칭은 사용자가 경로를 이해하는 데 필요하지 않아 화면에서는 숨긴다. 오류 제보 payload와 내부 단계 데이터에는 시설 ID를 유지한다.
- 여러 지상 출구가 있으면 `N, M번 출구 중 가까운 출구`, 하나면 `N번 출구 쪽`으로 안내한다.
- 출처 충돌은 기술적 근거를 나열하지 않고 하나의 `안전 경로 미확인` 카드로 안내한다.
