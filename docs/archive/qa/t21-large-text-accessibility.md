# T21 iOS·Android 큰 글자 접근성 QA

- 확인일: 2026-10-12
- 대상: 역 검색, 역 선택, 여정 결과, 오류·경고 상태
- iOS: iPhone 18 Pro Simulator / iOS 27 / 가장 큰 접근성 글자 크기
- Android: `medium_phone` Emulator / Android 16(API 36) / 글꼴 크기 200%

## QA에서 수정한 문제

- 홈 상단 브랜드와 베타 배지가 큰 글자에서 겹치지 않도록 줄바꿈과 확대 상한을 적용했다.
- 장식 아이콘은 글자 크기에 따라 불필요하게 확대되지 않도록 고정했다.
- 역 선택 헤더·탭·검색 결과·빈 상태 문구에 확대 상한과 줄바꿈을 적용했다.
- 여정 요약, 안내 단계, 시설 정보 행이 큰 글자에서 세로로 재배치되도록 수정했다.
- 공용 버튼에 화면별 레이아웃 스타일을 전달하면 기본 배경색이 사라지던 문제를 수정했다.
- React Native에서 사용 중단 예정인 `SafeAreaView` 대신 safe-area-context 구현을 사용했다.
- VoiceOver가 브랜드 화살표, 오류 아이콘, 단계 번호 같은 장식을 별도 정보로 읽지 않도록 숨겼다.
- 역 선택 제목과 설명, 여정 요약, 상태·단계 카드를 의미 단위로 묶어 중복 낭독을 제거했다.
- 오류 제보 창을 모달로 한정하고 상세 설명 입력란에 입력 안내를 추가했다.

## iOS VoiceOver 실기동 결과

- iOS 27 `Elbero VoiceOver QA` Simulator에서 Device Hub의 VoiceOver를 실제로 켜고 탐색했다.
- 홈은 서비스 제목 → 안내 → 출발역 → 교환 → 도착역 → 경로 찾기 순서로 이동했다.
- 역 선택은 `출발역 선택. 역과 노선을 함께 선택해요`를 제목으로 읽고, 닫기 → 검색·노선도 탭 → 검색 입력 → `답십리, 5호선` 결과 순서로 이동했다.
- 정상 여정은 2호선 시청 → 을지로입구 경로로 확인했다. 상태, 여정 요약, 1~7단계, 단계별 제보, 이전·다음 단계, 실시간 승강기, 데이터 확인 정보 순서로 이동했다.
- 열차 이동 단계에서 `빠른환승 6-1`, `을지로입구 방면`, `승강장 간격 안전`이 한 안내 단위로 읽혔다.
- 오류·안전 경로 미확인 카드는 장식 기호 없이 제목 → 원인 → 복구 행동 순서로 읽혔다.
- 오류 제보 창은 제목 → 개인정보 안내 → 현재 단계 → 오류 유형 → 상세 설명 입력 → 확인 순서로 이동했고, VoiceOver 이중 탭으로 상세 설명 키보드가 열렸다.

## 남은 제한

- 정상 여정은 실시간 API가 반환한 2호선 시청 → 을지로입구 경로로 확인했다. 시점에 따라 승강기 운행 상태가 달라질 수 있다.
- Android TalkBack과 글꼴 200%를 동시에 켜고 홈의 역 선택·경로 검색, 오류 결과의 뒤로가기·재시도, 예외 카드의 상태 탭과 설명이 의미 있는 순서로 노출되는 것을 확인했다.
- iOS VoiceOver는 Simulator에서 통과했다. 연결된 iPhone은 Developer Mode가 꺼져 있어 물리 기기 검증은 통과로 기록하지 않는다.
- Expo Go의 개발 도구 버튼은 접근성 트리에 노출되지만 배포 앱 UI가 아니라 개발 컨테이너 UI이므로 제품 결함에는 포함하지 않았다.
- 원천 데이터가 없거나 충돌하는 역은 [지원 노선 사용자 검증 대기 목록](../../research/supported-lines-user-verification-pending.md)에서 관리한다.
