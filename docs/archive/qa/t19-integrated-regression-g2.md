## 양 플랫폼 확인

### iOS

- iOS 시뮬레이터에서 시청 → 을지로입구 7단계 여정을 끝까지 확인했다.
- VoiceOver 읽기 순서, 상태·요약·단계 카드 및 오류 제보 화면을 확인했다.
- 증거: [iOS VoiceOver 정상 여정](../../qa/evidence/t21/ios-voiceover-normal-journey.png)

### Android

- Android 에뮬레이터에서 동일 경로의 7단계 카드와 다음 단계 이동을 확인했다.
- 2단계에서 앱을 종료하고 API를 중단한 뒤 다시 실행해 저장된 동일 여정과 현재 단계 `2 / 7`, 저장 시각 안내가 복구되는 것을 확인했다.
- 증거: [Android 2단계 진행](../../qa/evidence/t19/android-journey-step-2.png), [Android 오프라인 재실행 복구](../../qa/evidence/t19/android-offline-recovery.png)

## 핵심 기능 회귀

- 검색·역 선택: 지원 노선 배지, 동일 역 오류, 미지원·검색 결과 없음 상태를 테스트로 확인했다.
- 여정 안내: 진입·개찰구·승강장 엘리베이터·열차·환승·퇴장 순서를 대표 경로에서 확인했다.
- 운행 중지·누락: 추천 제외와 단일 사용자 오류 카드, 재탐색 안내를 확인했다.
- 오프라인: 저장된 여정·현재 단계·저장 시각 복구와 손상·버전 불일치 snapshot 폐기를 테스트했다.
- 오류 제보: 여정·단계·시설·데이터 버전 자동 포함, 메일 작성과 복사 대안을 테스트했다.
- 접근성: 큰 글자, 색 외 호선 표기, VoiceOver·TalkBack 읽기 순서를 T21 결과로 재확인했다.

## G2 판정

**통과**로 판정한다. 현재 내부 버전은 지원 중인 2·3·4·5·7호선에서 검색부터 퇴장까지 하나의 여정으로 연결되고, 환승·오류·오프라인 복구·제보·접근성 경로가 공용 계약을 통해 동작한다. iOS 시뮬레이터와 Android 에뮬레이터에서 대표 여정을 실행했고 양 플랫폼 번들도 생성됐다.

이 판정은 내부 통합 게이트 통과이며 앱 스토어 출시 승인을 의미하지 않는다.

## 알려진 제한과 다음 작업

- 일부 3·4·7호선 및 환승 경로는 실시간 시설 ID 연결 또는 원천 값이 없어 `안전 경로 미확인`으로 표시된다. 임의로 안전 경로를 확정하지 않는다.
- 현재 경로 엔진은 1~9호선·공항철도·용인에버라인·김포골드라인·신림선·신분당선·수인분당선·GTX-A의 16개 노선을 지원한다. 에버라인은 기흥역에서 수인분당선과 연결된다.
- 실제 역사 동선·시설 위치 검증은 T20에서 진행한다.
- 실제 iPhone은 개발자 모드가 꺼져 있고 Android 실기기 검증 기록은 없다. 실기기 접근성·오프라인 검증은 T21의 남은 범위로 유지한다.
- 사용자 검증 대기 항목은 [지원 노선 사용자 검증 대기 목록](../../research/supported-lines-user-verification-pending.md)에서 계속 관리한다.
