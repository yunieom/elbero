## 2. 방향별 차량·문 확인 (6역)

`stationElevatorCarNumber` 값이 비어 있거나 플랫폼 방향 코드가 충돌하는 항목이다. 괄호 안은
다른 API에서 읽은 후보이며 정답 판정은 하지 않았다.

| 역 | 확인할 내용 | 후보 |
| --- | --- | --- |
| 수락산 | 도봉산 방면 / 마들 방면 | 도봉산 `1-1`, 마들 `8-2` |
| 청담 | 장암 방면 / 석남 방면 | 장암 `7-4`, 석남 `2-1` |
| 남구로 | 장암 방면 / 석남 방면 | 장암 `1-4`, 석남 `8-2` |
| 산곡 | 부평구청 방면 / 석남 방면 플랫폼 매핑 | 차량·문 API는 양쪽 `5-1`, 시설 API는 양쪽 `4-4` |
| 석남 | 산곡 방면과 종착 승강장 매핑 | 1번 승강장 `1-3`, `7-3`; 2번 승강장 `2-2`, `8-4` |

추가로 장암은 차량·문 API가 1번 승강장 `4-3`만 반환하고, 도봉산 방면으로 표기된 2번
승강장에는 값이 없다. `장암 → 도봉산` 출발 안내에도 `4-3`을 사용할지 확인이 필요하다.

## 3. 사용자가 확인하지 않아도 되는 항목

- 운행 층 차이 26역: `stationElevator` 값을 사용한다.
- 나머지 차량·문 값 차이: `stationElevatorCarNumber` 값을 사용하고 방향은 7호선 순서
  `장암 ↔ 석남`으로 연결한다.
- 이격거리: `green`은 안내, `yellow`는 경고 후 안내, `red`는 제외하고 인접 안전 문으로
  대체한다.
- 역명: 앱 표기는 `총신대입구(이수)`로 통일한다.
