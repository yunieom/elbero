## 이격거리 전체 집계

| 전체 레코드 | green | yellow | red | 값 없음 |
| ---: | ---: | ---: | ---: | ---: |
| 45,543 | 34,956 | 8,067 | 1,332 | 1,188 |

- `green`: 0cm 이상 10cm 이하
- `yellow`: 10cm 초과 15cm 이하
- `red`: 15cm 초과
- API가 이격거리 행 자체를 반환하지 않은 역은 `값 없음` 레코드 수와 별도로 노선별 보고서의 제공 범위에 기록한다.

## 주요 제공 범위 차이

- 서울교통공사 승강기 가동현황 API는 서울교통공사 외 운영기관 노선을 대부분 반환하지 않는다. 이를 시설 오류가 아닌 API 제공 범위 차이로 기록한다.
- 인천공항 자기부상철도는 6개 역 모두 승강장·인접 차량·문·이격거리 행이 없다.
- 수인분당선은 이격거리 값 없음 816건, 경춘선은 128건, 공항철도는 60건이다.
- 인천 1호선 연장역 검단호수공원·신검단중앙·아라는 승강장은 있지만 인접 차량·문과 이격거리 행이 없다.
- 비서울 운영기관은 숫자 역 코드가 서울 지하철과 우연히 같을 수 있어 역명까지 일치할 때만 서울 API 행을 연결한다.

## 해석할 때 주의할 점

- 차이 항목은 `지상 출구`, `운행 층`, `인접 차량·문`, `이격거리 연결`, `역명` 단위다.
- 한 차이 항목에 값 불일치와 API 값 없음이 함께 있을 수 있으므로 유형별 건수는 서로 배타적이지 않다.
- 이 보고서는 자동 비교 결과다. 실제 정답은 지도·편의정보·현장 확인 뒤 `data/verification` 아래 수동 검증값으로 별도 관리한다.
