## 비교 기준

- 지상 출구: 네 API에서 추출한 출구 번호 집합이 다르면 기록한다.
- 운행 층: KRIC 시설 현황과 서울교통공사 현황의 층 구간 집합이 다르면 기록한다.
- 차량·문: 세 API의 차량-문 번호 집합이 다르면 기록한다.
- 승강장·이격거리: 승강장, 인접 차량·문, 문별 이격거리 레코드가 연결되지 않으면 기록한다.

- `값 차이`와 `API 값 없음`은 별도 유형으로 표시한다.
