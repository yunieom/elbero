## 해석할 때 주의할 점

- 차이 항목은 `지상 출구`, `운행 층`, `인접 차량·문`, `이격거리 연결`, `역명` 단위다.
- 한 차이 항목에 값 불일치와 API 값 없음이 함께 있을 수 있으므로 유형별 건수는 서로 배타적이지 않다.
- 같은 숫자 역 코드를 여러 운영기관이 사용할 수 있어 역은 `운영기관 코드 + 역 코드`로 구분한다.
- 서울교통공사 API는 다른 운영기관 역의 값을 제공하지 않을 수 있다. 이를 오답으로 판정하지 않고 `API 값 없음`으로 기록한다.
- 이 보고서는 자동 비교 결과다. 실제 정답은 지도·편의정보·현장 확인 뒤 `data/verification` 아래 수동 검증값으로 별도 관리한다.
