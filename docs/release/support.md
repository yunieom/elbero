# 엘베로 지원 안내

- 운영자: **출시 전 실제 운영자명 입력 필요**
- 지원 이메일: **출시 전 실제 지원 이메일 입력 필요**

## 앱에서 잘못된 정보를 발견했을 때

여정 결과의 해당 단계에서 `이 단계 정보 제보`를 선택해 주세요. 앱이 여정 ID, 데이터 버전, 역, 단계와 시설 ID를 메일 초안에 자동으로 포함하므로 문제를 재현하는 데 도움이 됩니다.

제보 유형:

- 잘못된 진입·퇴장 동선
- 엘리베이터 위치 또는 출구 번호 오류
- 승강기 운행 상태 불일치
- 권장 차량·문 또는 승강장 간격 오류
- 기타 안내 문제

## 긴급한 상황

엘베로의 안내는 역내 안전 표지와 직원 안내를 대체하지 않습니다. 공사, 고장 또는 현장 통제로 앱과 실제 동선이 다르면 이동을 중단하고 역무원에게 도움을 요청하세요. 긴급 상황은 해당 지역의 긴급 전화로 연락하세요.

## 데이터 상태의 의미

- `운행 중`: 관측 시각 기준으로 필요한 승강기가 운행 중입니다.
- `운행 중지`: 필요한 승강기의 중지 상태가 확인되어 추천에서 제외합니다.
- `승강장 간격 미확인`: 공공데이터에 해당 거리 값이 없어 안전 등급을 추정하지 않습니다.
- `안전 경로 미확인`: 필수 위치 정보가 없거나 출처가 충돌해 안전 경로로 확정하지 않습니다.

## 지원 범위

1~9호선·공항철도·용인에버라인·김포골드라인·신림선·신분당선·수인분당선·GTX-A를 지원합니다. 용인에버라인은 기흥역에서 수인분당선과 연결되며, GTX-A는 운정중앙–서울역과 수서–동탄을 분리된 운행 구간으로 안내합니다. 지원 범위는 앱의 데이터 확인일과 함께 갱신됩니다.

## 연락처

지원 이메일은 앱의 `서비스 정보 → 지원 및 안전 안내`와 스토어 등록 정보에서 동일한 주소를 사용합니다.

## 요금·계정·광고

현재 엘베로에는 회원 계정, 유료 기능, 구독, 인앱결제와 광고가 없습니다. 결제가 없으므로 환불이나 구독 해지 절차도 없습니다.
