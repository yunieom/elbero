# 엘베로 개인정보 처리방침 초안

- 시행 예정일: 첫 공개 출시일
- 최종 확정 필요: 운영자 이메일, API 배포 사업자와 보안 로그 보존 기간, 공개 문서 URL

엘베로는 계정 없이 지하철 엘리베이터 중심 이동 경로를 확인할 수 있는 앱입니다. 서비스 제공에 필요하지 않은 정밀 위치나 이동 이력을 수집하지 않습니다.

## 앱에서 처리하는 정보

### 여정 조회

사용자가 선택한 출발역·도착역의 역 코드가 경로 조회를 위해 엘베로 API 서버로 전송됩니다. 정밀 위치, 연락처, 기기 사진, 광고 식별자는 여정 조회에 사용하지 않습니다.

### 기기에 저장하는 정보

최근 조회한 여정, 현재 안내 단계, 데이터 버전과 저장 시각을 사용자의 기기에 저장합니다. 이 정보는 지하에서 네트워크가 끊기거나 앱을 다시 실행했을 때 동일한 안내를 복구하기 위해 사용합니다. 새 여정을 검색하면 이전 여정은 교체됩니다.

### 오류 제보

사용자가 `이 단계 정보 제보`를 선택하면 여정 ID, 데이터 버전, 경로 ID, 단계, 역, 기존 안내, 시설 ID와 사용자가 입력한 설명으로 메일 초안을 만듭니다. 앱은 메일을 자동 발송하지 않으며 사용자가 메일 앱에서 내용을 확인하고 직접 전송합니다. 메일 앱을 사용할 수 없으면 같은 내용을 클립보드에 복사할 수 있습니다.

## 수집하지 않는 정보

- 회원 계정과 비밀번호
- GPS 기반 정밀 위치와 이동 경로 이력
- 연락처, 사진, 마이크·카메라 정보
- 광고 식별자와 광고 목적 프로필
- 결제 정보

## 외부 데이터와 서비스

경로와 시설 안내에는 국토교통부 철도산업정보센터(KRIC)와 서울교통공사 등 공공데이터를 사용합니다. 오류 제보를 전송하면 사용자가 선택한 메일 서비스의 개인정보 처리방침이 적용됩니다. 운영 API 배포 사업자가 정해지면 네트워크 보안 로그의 항목과 보존 기간을 이 문서에 추가합니다.

## 보유와 삭제

기기에 저장된 현재 여정은 새 검색으로 교체되며 앱을 삭제하면 함께 삭제됩니다. 이메일로 접수된 오류 제보의 보존 기간은 운영자 이메일과 처리 절차가 확정될 때 명시합니다. 사용자는 전송 전에 메일 초안의 설명과 포함 정보를 수정하거나 전송을 취소할 수 있습니다.

## 이용자의 선택

오류 제보는 선택 기능이며 제보하지 않아도 경로 안내를 사용할 수 있습니다. 저장된 여정을 제거하려면 새 여정을 검색하거나 앱 데이터를 삭제할 수 있습니다.
