# 엘베로 개인정보 처리방침

- 시행일: 2026-10-30
- 적용 서비스: 엘베로 iOS·Android·웹 앱
- 운영자명: 출시 전 `EXPO_PUBLIC_OPERATOR_NAME`의 실제 운영자명으로 교체
- 개인정보 문의: 출시 전 `EXPO_PUBLIC_REPORT_EMAIL`의 실제 주소로 교체

엘베로는 계정 없이 이용할 수 있으며, 경로 안내에 필요하지 않은 개인정보를 수집하지 않습니다.

## 1. 처리하는 정보와 목적

### 여정 조회

출발역과 도착역의 역 코드가 경로 계산을 위해 엘베로 API로 전송됩니다. 앱 서버는 요청에 응답한 뒤 조회 내역을 별도 데이터베이스에 저장하지 않습니다. GPS 위치, 광고 식별자와 계정 식별자는 요청에 포함되지 않습니다.

### 기기 저장

최근 조회 여정, 현재 안내 단계, 데이터 버전과 저장 시각을 사용자의 기기에 저장합니다. 지하에서 네트워크가 끊기거나 앱을 다시 실행했을 때 같은 안내를 복구하기 위한 정보입니다.

### 오류 제보

사용자가 `이 단계 정보 제보`를 선택하면 여정 ID, 데이터 버전, 경로 ID, 단계, 역, 안내, 시설 ID와 사용자가 입력한 설명으로 메일 초안을 만듭니다. 앱은 자동으로 전송하지 않으며 사용자가 메일 앱에서 내용을 확인하고 직접 전송해야 운영자에게 전달됩니다. 발신 이메일 주소와 사용자가 작성한 내용은 오류 확인과 답변에 사용됩니다.

## 2. 수집하지 않는 정보

- 회원 계정, 비밀번호, 생년월일
- GPS 기반 정밀 위치와 이동 이력
- 연락처, 사진, 카메라, 마이크 정보
- 광고 식별자와 광고·행동 분석 정보
- 결제 정보

Android 빌드에서는 위치, 카메라, 마이크, 연락처, 미디어, 알림과 광고 ID 권한을 차단합니다. iOS 앱도 해당 권한을 요청하지 않습니다.

## 3. 보유와 삭제

- 기기에 저장된 여정은 앱의 `서비스 정보 → 저장된 여정 삭제`에서 즉시 삭제할 수 있습니다.
- 새 여정을 조회하면 기존 여정은 교체되며 앱을 삭제하면 기기 저장 정보도 함께 제거됩니다.
- 이메일로 접수된 오류 제보는 오류 확인과 답변에 필요한 기간 동안만 보관합니다. 사용자가 삭제를 요청하면 법령상 보관 의무가 없는 범위에서 삭제합니다.
- 계정을 생성하지 않으므로 삭제할 회원 계정은 없습니다.

## 4. 외부 서비스와 제3자

경로와 시설 안내에는 국가철도공단 철도산업정보센터(KRIC), 서울교통공사 등의 공공데이터를 사용합니다. 이 기관에 사용자 정보를 제공하지 않습니다.

오류 제보를 전송할 때는 사용자가 선택한 메일 서비스의 개인정보 처리방침이 적용됩니다. 엘베로에는 광고, 행동 분석, 소셜 로그인 SDK가 없습니다.

## 5. 쿠키와 로컬 저장소

네이티브 앱은 쿠키를 사용하지 않습니다. 웹 앱은 최근 여정 복구에 필요한 브라우저 로컬 저장소만 사용하며 광고·분석 쿠키를 사용하지 않습니다. 따라서 현재 쿠키 동의 배너가 필요한 비필수 쿠키가 없습니다.

## 6. 아동과 민감정보

엘베로는 아동을 대상으로 계정, 나이 또는 보호자 정보를 수집하지 않습니다. 오류 제보 설명에는 이름, 연락처, 건강정보 등 불필요한 개인정보를 입력하지 말아 주세요.

## 7. 안전조치

- 운영 API는 HTTPS로 통신합니다.
- 앱과 웹 서버는 요청 접근 로그를 저장하지 않습니다.
- 공공데이터 서비스 키는 앱에 포함하지 않고 서버 환경변수로 관리합니다.
- iOS Privacy Manifest에 사용 SDK의 필수 API 사용 사유를 기록하고 추적·수집 없음으로 선언합니다.
- Docker 로그는 크기와 파일 수를 제한합니다.

## 8. 이용자의 권리와 문의

사용자는 기기 저장 정보를 직접 삭제할 수 있고, 이메일로 보낸 오류 제보의 열람·정정·삭제를 운영자에게 요청할 수 있습니다.

- 처리자: **출시 전 실제 운영자명 입력 필요**
- 개인정보 문의·삭제 요청: **출시 전 실제 지원 이메일 입력 필요**

방침이 변경되면 시행일과 변경 내용을 앱과 공개 문서에 갱신합니다.
