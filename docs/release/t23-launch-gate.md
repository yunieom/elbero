# T23 출시 관문과 버그 분류

- 판정일: 2026-10-30
- 현재 판정: **조건부 보류**
- 원칙: 모든 지원 역을 현장에서 확인할 때까지 출시를 미루지 않는다. 대표 동선과 실패 처리의 안전성을 확인하고, 나머지는 데이터 신뢰 상태와 사용자 제보로 운영한다.

## 현장 검증 범위 결정

출시 전 현장 대조는 아래 두 경로로 제한한다.

1. 직통: 답십리 → 강동
2. 환승: 답십리 → 홍대입구

각 경로에서 지상 엘리베이터, 이동 층, 개찰구, 진행 방향, 권장 차량·문, 환승 엘리베이터, 퇴장 출구만 대조한다. 틀린 방향이나 끊긴 동선이 발견되면 해당 경로 또는 시설을 추천에서 제외하고 수정 전까지 `안전 경로 미확인`으로 표시한다.

## 출시 후 검증 정책

- 앱이 지원하는 모든 역을 현장 검증 완료로 홍보하지 않는다.
- KRIC·서울교통공사 정보가 없거나 충돌하면 미확인 상태를 사용자에게 표시한다.
- 사용자는 각 단계에서 여정 ID·단계·시설 ID가 포함된 오류 제보를 보낼 수 있다.
- 제보된 위험 동선은 우선 추천에서 제외하고, 원천 API·지도·현장 확인 후 복구한다.
- 반복 제보는 노선·역·방향·시설별로 묶어 우선순위를 정한다.

## 버그 분류

### 출시 차단

- 잘못된 진행 방향 또는 존재하지 않는 출구를 안전 경로로 추천
- 운행 중지 엘리베이터를 필수 경로로 추천
- 데이터 미확인을 안전으로 표시
- 앱 시작·검색·결과 화면 진입 불가
- 현재 여정 복구가 다른 여정으로 바뀜

### 출시 전 수정 권장

- 문구 잘림, 큰 글자에서 핵심 버튼 접근 불가
- 스크린 리더 순서 오류
- 오류 제보 메일 또는 복사 대안 실패

### 출시 후 개선 가능

- 추가 수도권 노선 확대
- 더 많은 역의 현장 확인
- 제보 서버와 처리 상태 추적
- 추천 이유와 출구 주변 목적지 정보 고도화

## 출시 결정 조건

두 대표 동선에 출시 차단 오류가 없고, 운영 API·제보 이메일·양 플랫폼 패키지가 준비되면 첫 출시를 진행한다. 독립 참여자 사용성 관찰과 전체 역 현장 대조는 출시 후 Beta 운영으로 이관한다.
