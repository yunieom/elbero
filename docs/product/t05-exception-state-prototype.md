  F12 오류 제보
- 선행 설계: [`T04 S01~S06 정보 구조`](./t04-information-architecture.md)

## 시제품 진입

5호선 QA 홈에서 `QA 예외 상태 시제품 보기`를 선택한다. 시제품은 다음 상태를 백엔드
상태와 무관하게 전환할 수 있어 회귀 QA에 사용한다.

| 상태 | 화면 표현 | 복구 행동 |
| --- | --- | --- |
| 안전 경로 미확인 | 일반 경로는 유지하되 추천하지 않는 이유와 확인 항목을 한 카드에 표시 | 현장 안내 확인 또는 다른 역 검색 |
| 승강기 운행 중지 | 필수 시설의 보수 상태와 다른 경로 확인 안내 | 다른 후보 경로 또는 검색 복귀 |
| 조회 실패 | 서버 응답 실패 설명과 경고 아이콘 | `다시 시도` |
| 오프라인 | 인터넷 연결 확인과 현재 선택 유지 안내 | 연결 복구 후 `다시 시도` |

역 선택 화면에는 별도로 역 목록 로딩, 로딩 실패·재시도, 검색 결과 없음, 출발·도착
동일 오류가 구현되어 있다. 여정 결과 화면에는 로딩, 조회 실패·재시도, 이용 가능,
운행 중지, 안전 경로 미확인 상태가 구현되어 있다.

## 공통 컴포넌트 상태

| 컴포넌트 | 정상 | 오류·빈 상태 | 접근성 |
| --- | --- | --- | --- |
| `StationField` | 선택 역과 호선 표시 | 미선택 안내, 동일 역 검증 문구 | 버튼 역할과 선택 역을 한 라벨로 읽음 |
| `StationPickerModal` | 검색 가능한 역 목록 | 로딩, 로딩 실패·재시도, 결과 없음 | 제목·검색창·역 버튼 순서 유지 |
| `JourneyStatusCard` | 현재 이용 가능 | 운행 중지, 안전 경로 미확인, 중복 이유 제거 | 상태→설명→확인 항목을 하나의 라벨로 읽음 |
| `GuidanceStepCard` | 순서·역·안내 | yellow 경고, red 후보 제외 | 단계·유형·역·안내·간격 순서로 읽음 |
| `DataStatus` 영역 | 시설별 상태와 확인 시각 | 미확인 상태와 최대 지연 표시 | 색상과 함께 상태 문구 제공 |

## 작은 화면·큰 글씨 대응

- 모든 QA 상태 선택·뒤로 가기·재시도 버튼은 최소 48px 높이 또는 너비를 사용한다.
- 화면은 고정 높이 컨테이너 대신 세로 스크롤과 내용 높이를 사용한다.
- 상태 선택은 가로 탭 묶음이 아니라 세로 목록이라 글씨 확대 시 옆 항목과 겹치지 않는다.
- 제목과 설명에 줄 높이를 지정하고 React Native의 기본 글씨 확대를 막지 않는다.
- 카드 안의 행동 버튼은 가로 전체 폭을 사용해 작은 화면에서도 잘리지 않게 한다.
- 실제 iOS·Android의 최대 글씨, VoiceOver·TalkBack 검증은 T21에서 반복한다.

## 검증 결과

- Expo SDK 57 웹 내보내기 성공
- TypeScript 검사 통과
- 앱에서 네 상태를 모두 클릭해 상태별 제목·설명·아이콘을 확인
- 조회 실패 상태에서 `다시 시도` 후 라이브 메시지 노출 확인
- 접근성 트리에서 탭 목록, 선택 상태, 경고, 버튼과 상태 카드 읽기 순서 확인
- 화면 캡처에서 세로 흐름, 카드 폭, 복구 버튼 배치 확인
