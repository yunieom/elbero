## 실시간 승강기 연결 규칙

- 여정에 실제로 필요한 출발역 지상 진입, 출발 승강장, 환승 승강장, 도착 승강장, 도착역 지상
  퇴장 시설만 평가한다.
- 서울교통공사 응답의 역 코드, 시설명, 운행 구간, 설치 위치가 모두 일치할 때만 실시간 상태를
  연결한다.
- 여러 시설 중 하나만 이용해도 되는 구간은 `any`, 모든 층 구간을 통과해야 하는 구간은 구간별
  필수 그룹으로 평가한다.
- `사용가능`은 이용 가능, `보수중`은 운행 중지, 값 누락·시설 연결 불일치는 안전 경로 미확인으로
  표시한다.
- API에 시설이 없는 역을 임의로 다른 시설에 연결하지 않는다. 일반 경로는 보여 주되 안전 경로
  미확인으로 표시한다.
- 상태 원본은 한 시간 동안 캐시하고 화면에 확인 시각과 최대 지연 시간을 함께 표시한다.

## 앱 QA 흐름

1. 출발역과 도착역을 5호선 56개 역에서 검색해 선택한다.
2. 같은 역을 선택하면 검증 메시지를 표시한다.
3. 결과 화면에서 추천 가능, 운행 중지, 안전 경로 미확인을 구분한다.
4. 이동 순서에서 출구, 방향, 차량·문, 승강장 이격거리, 환승 안내를 확인한다.
5. 실시간 승강기 목록에서 여정에 필요한 각 시설의 상태를 확인한다.
6. 데이터 확인 시각, 최대 60분 지연, 경로 검증일을 확인한다.

우선 QA 예시는 `답십리 → 굽은다리`다. 현재 두 API의 굽은다리 지상 출구 번호가 다르므로 일반
이동 경로는 표시하고 지상 출구 연결은 안전 경로 미확인으로 표시되어야 한다.
