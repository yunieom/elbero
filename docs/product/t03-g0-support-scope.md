# T03 · 대표 여정 지원 범위와 G0 점검

- 결정일: 2026-09-17
- 연결 기능: F03 여정 조합, F10 정보 신뢰도와 예외 처리
- 선행 증거: [`T02 공공데이터 검증 기록`](../research/t02-f03-public-data-validation.md)
- G0 판단: 조건부 통과

## 첫 지원 범위

| 여정 | 지원 방식 | 현재 결정 |
| --- | --- | --- |
| 답십리→강동 | 5호선 직통 | 1번 출구를 기본 퇴장 경로로 안내. 2-1번 출구는 서울 상태 목록에 연결할 시설이 없어 `unknown` |
| 답십리→홍대입구 | 5호선→2호선 환승 | 동대문역사문화공원을 우선 후보로 사용. 필수 승강기가 운행 중지 또는 미확인이면 을지로4가의 검증된 후보를 평가 |

위 두 여정 외 조합은 `UNSUPPORTED_JOURNEY`로 반환한다. 아직 검증되지 않은 연결을
일반 최단경로처럼 제공하지 않는다.

## 시설 상태 연결 규칙

KRIC와 서울교통공사 데이터에는 공통 시설 ID가 없다. 따라서 역 코드, 서울 승강기명,
운행 층, 설치 위치가 모두 검증표와 일치할 때만 시설 상태를 연결한다. 하나라도 달라지면
자동으로 비슷한 이름을 선택하지 않고 `unknown`으로 처리한다.

- `all`: 그룹의 모든 엘리베이터가 운행 중이어야 경로를 사용할 수 있다.
- `any`: 출구처럼 대체 가능한 시설 중 하나 이상이 운행 중이면 경로를 사용할 수 있다.
- `out_of_service`: 필수 시설이 `보수중`일 때 사용한다.
- `unknown`: 서울 상태 행이 없거나 검증된 연결 조건이 달라졌을 때 사용한다.
- 추천 경로는 모든 필수 그룹이 `operational`인 후보 중 우선순위가 가장 높은 하나다.

## G0 점검

| 항목 | 판정 | 근거 또는 제한 |
| --- | --- | --- |
| 방향별 출발역 진입 | 충족 | 답십리 마장·장한평 방면 KRIC 동선과 서울 내부·외부 승강기 연결 |
| 환승 경로 | 충족 | 동대문역사문화공원과 을지로4가의 방향별 KRIC 환승 단계 확인 |
| 도착역 퇴장 | 조건부 충족 | KRIC 진입 동선을 역순 사용한다고 응답 근거에 명시 |
| 현재 승강기 상태 | 조건부 충족 | 서울 API는 최대 1시간 지연되고 행별 관측 시각이 없음 |
| 고장 시 대체 환승 | 대표 여정 충족 | 동대문역사문화공원 필수 시설 고장 fixture에서 을지로4가 선택 |
| 일반 노선 전체 지원 | 미충족·범위 제외 | 검증된 시설 연결표가 없는 역 조합은 제공하지 않음 |

G0는 대표 여정을 구현할 근거가 확보되었다는 의미로만 통과한다. 전체 서울 지하철의
무장애 경로가 검증되었다는 의미가 아니다.

## API 증거

```text
GET /journeys/plan?originStationCode=2543&destinationStationCode=2549
GET /journeys/plan?originStationCode=2543&destinationStationCode=239
```

응답에는 정적 경로 데이터 버전, 검증일, 서울 상태 수집 시각, 최대 지연 시간, 후보별
차단 이유, 시설별 연결 여부와 원본 상태를 포함한다.
