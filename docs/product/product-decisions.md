# 제품 범위와 UX 결정

- 기준일: 2026-10-30
- 목적: 사용자가 엘리베이터 중심 경로와 정보의 신뢰 범위를 이해하도록 하는 현재 제품 기준

## 해결할 문제

1. 지상 출구부터 승강장까지, 환승역 내부, 도착 승강장에서 지상까지의 엘리베이터 동선을 연결한다.
2. 실시간 승강기 운행 상태를 반영하고, 운행 중지 시설이 있으면 대체 경로 또는 원래 경로와 명확한 경고를 제공한다.
3. 승강기 인접 차량·문과 승강장 이격거리를 연결해 교통약자가 안전한 위치를 선택하도록 돕는다.

## 현재 지원 범위

- 경로 엔진: 1~9호선, 공항철도, 용인에버라인, 김포골드라인, 신림선, 신분당선, 수인분당선, GTX-A
- 같은 노선과 등록된 환승 그래프를 통한 노선 간 여정
- 서울교통공사 승강기 가동현황을 이용한 실시간 상태 결합
- 출발·도착 검색, 단계별 안내, 오프라인 snapshot, 오류 제보

정확한 검증 잔여 항목은 [`지원 노선 검증 대기 목록`](../research/supported-lines-user-verification-pending.md)만 갱신한다.

## 핵심 화면 흐름

1. 출발역과 도착역을 역명·호선으로 선택한다.
2. 노선, 방향, 환승 횟수와 엘리베이터 중심 경로를 요약한다.
3. 지상 엘리베이터 → 개찰구 → 승강장 → 열차 → 환승 → 도착역 퇴장 순서로 안내한다.
4. 차량·문 위치는 `빠른환승` 또는 `빠른하차`로 표시한다.
5. 사용자는 현재 단계를 저장하고 오프라인·재실행 뒤 이어서 확인할 수 있다.

## 안전·상태 정책

- 이격거리 0~10cm는 `green`, 10cm 초과~15cm는 `yellow`, 15cm 초과는 `red`다.
- `yellow`는 경고와 함께 안내하고 `red`는 추천에서 제외한다.
- 시설 정보가 없거나 충돌하면 일반 경로를 표시하되 `안전 경로 미확인`으로 표시한다.
- 필수 승강기가 모두 운행 중지여도 원래 이동 순서는 숨기지 않는다. 추천 경로는 비우고, 운행 중지 시설과 대체 경로 부재를 빨간 상태 카드에 표시한다.
- 출처별 지상 출구가 충돌하면 검증값을 우선하며, 사용자 화면에는 내부 데이터 충돌 과정을 노출하지 않는다.
- 단일 출구는 `N번 출구 쪽`, 복수 출구는 `N, M번 출구 중 가까운 출구`로 안내한다.

## 정보 우선순위

1. 사용자가 확인한 방향·차량·문·출구 값
2. KRIC 이동경로와 시설 정보의 합의값
3. 서울교통공사 실시간 운행 상태
4. 합의되지 않은 원천값은 자동 확정하지 않고 검증 대기로 남김

## 접근성 원칙

- 색만으로 노선을 구분하지 않고 호선 번호·약칭을 함께 표시한다.
- 큰 글자에서도 핵심 안내와 버튼이 잘리지 않게 한다.
- VoiceOver·TalkBack 라벨은 화면의 시각적 순서와 같은 순서로 읽힌다.
- 기술적 근거보다 사용자가 지금 해야 할 행동과 위험 상태를 먼저 표시한다.
